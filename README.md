# Proiect Baze de Date – Cinema Management

Acest proiect a fost realizat în cadrul materiei **Baze de Date** și are ca scop proiectarea și implementarea unei baze de date pentru gestionarea activității unui cinema.

## Descriere generală

Baza de date a fost creată pentru a gestiona informații legate de filme, proiecții, săli, clienți, bilete și personal. Proiectul parcurge toți pașii esențiali în dezvoltarea unei baze de date relaționale: de la modelare conceptuală și logică, până la implementare SQL și interogări.
